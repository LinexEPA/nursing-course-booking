# 115年度護理部 EPAs 系列課程｜學分補查

這個模組在既有 Learning Hub 新增一個入口。原課程預約、DOPS、EPA、教學工具均不變。

## 部署架構

- GitHub Pages 的 `credit-check.html` 僅提供入口，不蒐集教師資料。
- Google Apps Script 的 `Index.html` 才是實際填寫畫面，透過 HTTPS 把資料傳給 `Code.gs`。
- 私人 Google 試算表的 `補查資料`、`異動紀錄` 保存補查記錄，未經查核不自動入學分。
- 完整身分證字號在伺服端計算 HMAC-SHA256，試算表僅保存不可逆比對碼與遮蔽顯示。Script Properties 保存秘密金鑰。

## 回填欄位

1. 單位、護理長全名。
2. 臨床教師全名、完整身分證字號（僅臨床教師需要，原文不寫入試算表）。
3. 第一堂「甚麼學員可以被信賴」、第二堂「你以為的，是我以為的？」之完成情形。
4. 第三堂「老師～換你上場！」之完成情形；已完成評核時另填 PGY 學員全名。

依使用者確認，**不要求護理長信箱、不發驗證碼、也不使用填寫碼**。填寫者的單位與姓名為自填，不能視為身分認證。

## 人工查核提醒

- 第一、二堂：承辦人以課程**簽到單**核對；「送出登記」不代表已經認列學分。
- 第三堂：承辦人以**繳回的實體評核表**核對，須由臨床教師及受評 PGY 學員親筆簽名，再由護理長核章；核對後才可入學分。
- 每次提交都另存一筆，保留時間與自填者資訊，避免公開表單的匿名編修改寫先前紀錄。重複與不實資料須由承辦人查核。
- 期限：**2026/12/05 23:59:59（Asia/Taipei）**，後端拒絕逾期登記。逾期須呈報護理部裁示。

## 正式啟用

1. 由院內確認以外部 Google Apps Script / 私人 Google Sheets 收集臨床教師完整身分證字號的蒐集告知、必要性、存取及保存期限。
2. 在獨立 Google Sheet 綁定 Apps Script，貼入 `Code.gs` 與 `Index.html`，從編輯器執行 `initialize()`。
3. Web App 部署「執行身分：我」、「存取：所有人」。因無登入，任何取得網址者都可提交補查，務必以簽到單與紙本表單人工核對。
4. 以虛構資料測試提交與遮蔽儲存後，移除測試紀錄。將正式 Web App `/exec` URL 配置於 GitHub 的 `credit-check.html`，切換 `OPEN_FOR_REQUESTS` 為 true。
5. 試算表不可設為公開或「知道連結的任何人」。不可在 GitHub、URL、郵件、前端儲存或日誌留下教師完整身分證字號。

## 安全限制

本表單無填寫者認證，**無法保證自填的護理長姓名為真**，也不能阻止知道連結的人提交虛假或大量登記。人工核對可以防止直接誤認列學分，但不等於認證或防垃圾資料。若院內規範需要身分認證或禁止外部雲端蒐集身分證字號，應改採院內核准的平台。補查結束後依核定保留期限清除資料及相關備份。
